
# Project 01: Enterprise Network Subnetting

## Overview
A practical Cisco Packet Tracer project focused on IPv4 subnetting using Variable Length Subnet Masking (VLSM).

## Objective
Design an IP addressing scheme for five company departments using the allocated network 192.168.10.0/24.

## Department Requirements

| Department | Required Hosts |
|---|---:|
| Administration | 50 |
| IT | 25 |
| Finance | 12 |
| Human Resources | 6 |
| Management | 2 |

## Technologies
- Cisco Packet Tracer
- IPv4 addressing
- VLSM subnetting
- Network topology design
